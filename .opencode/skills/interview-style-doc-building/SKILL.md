# Interview-Style Doc Building

The user's preferred mode for creating durable strategic docs. AI does NOT propose content — AI asks one question, the user answers, AI patches the file, AI asks the next question. The file IS the conversation's output, updated incrementally.

## When to use

- Building a new SSOT file (life priorities, life vision, principles, frameworks, ranked lists).
- Filling out a structured doc the user explicitly wants to author themselves.
- Quarterly/annual reviews where the user's words go into the file.

**NOT for:** day planning, task triage, or anything where AI proposes content first.

## The Loop

1. **Create the file** with a skeleton (header, sections, "to be filled in" placeholders). Single write for the new file. After this, NEVER overwrite — only patch.
2. **Ask ONE question.** Concise. Specific. Single-faceted. Open-ended where possible.
3. **Wait for the answer.** Don't ask the next question yet.
4. **Patch the file** with the user's answer in the correct section.
5. **Re-ask** — next question, or follow-up if the answer was incomplete.
6. Repeat until the file is complete.

## Hard Rules

- **One question at a time.** Never dump multiple questions in a single message.
- **Patch, don't overwrite.** After the initial skeleton, use patch for every update.
- **Update the file BEFORE asking the next question.**
- **Lists from the user are UNORDERED SETS.** Never infer rank from order. Ask explicitly.
- **Ask dynamics, not names.** Don't ask "who is X?" — ask about the role/dynamic.
- **No snark, no attitude, no filler.**
- **No speculative additions.** Don't invent sections or "anything else?" prompts.

## Question Design

- **Domain-discovery, not confirmation.** "What wins?" — not "Is this #1?"
- **Surface new reality.** Each question pulls out info AI doesn't already have.
- **Engine-move framing.** "What's the thing that, if true, makes the rest obvious?"
- **Concrete over abstract.** "What's #2?" beats "Tell me about your second priority."

## Common Pitfalls

- Assuming order from a set — ALWAYS confirm rank explicitly
- Asking >1 question at once
- Overwriting file instead of patching sections
- Adding AI-generated content to fill sections
- Skipping file update between Q&A pairs
